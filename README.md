# Tilda RAG Chatbot

**Статус: проект запланирован. Рабочий чат-бот ещё не реализован и не развёрнут.**

AI-консультант для сайтов на Tilda, отвечающий по **актуальному опубликованному содержимому страниц**. Первое внедрение: [Comfortclinic.kz](https://comfortclinic.kz). Код и планируются как переиспользуемое решение для других Tilda-сайтов.

## Главная идея

Администратор меняет услуги, цены, врачей и чекапы **только в Tilda**. После публикации новые данные автоматически попадают в поисковый индекс. Отдельную базу знаний вручную заполнять или редактировать **не требуется**.

Публичный чат-бот **не получает доступ к административному Tilda MCP**. Он читает только предварительно очищенный индекс публичных страниц. Все ответы о ценах, составе услуг, врачах и контактах подкрепляются ссылками на актуальные URL. Если сведений нет, бот прямо об этом сообщает.

## Выбранный стек

| Компонент | Технология | Задача |
| --- | --- | --- |
| Источник знаний | Опубликованные страницы Tilda + sitemap.xml | Единственный источник фактов |
| Автоматическое обновление | GitHub Actions | Crawl, очистка, проверка, индексирование |
| Поиск | Версионированный индекс (JSON/текст на MVP, далее KV/R2/Vectorize при необходимости) | Быстрая выдача релевантных фрагментов |
| Chat API | Cloudflare Workers | Защищённый серверный API и вызовы LLM |
| Модель | Настраиваемый LLM provider | Формирование ответов по найденным источникам |
| Интерфейс | Виджет HTML/CSS/JS, встраиваемый в Tilda T123 | RU/KZ, адаптив, ссылка на страницы |
| Репозиторий | GitHub | Исходники, CI, roadmap, документация |

**Render не обязателен**. GitHub Pages подходит для статики виджета, но не может безопасно исполнять chat API с секретным LLM-ключом. Серверная функция Cloudflare Worker запускается по запросу. Оплата API модели и ограничения бесплатных тарифов уточняются перед реализацией.

## Архитектура

```text
Tilda published pages (comfortclinic.kz/sitemap.xml)
            │ HTTPS read-only crawler
            ▼
GitHub Actions: discover → fetch → extract → sanitize → diff → validate
            │ publish approved, versioned index
            ▼
       Search index / cache
            ▲ read-only
            │
Tilda T123 chat widget → Cloudflare Worker → retrieval → LLM
                                                    │
                                     grounded answer + source URLs
```

**Запрещено:** прямой вызов Tilda MCP пользователем бота; административные инструменты записи/публикации; ключи в JS; ответы по черновикам, закрытым страницам и административным настройкам; хранение медицинских сообщений в индексах и логах.

## Основные сценарии

- «Какие у вас есть чекапы щитовидной железы?» → программы, фактические цены, кнопки на страницу источника.
- «Как записаться к врачу?» → только опубликованные контакты и реальный способ записи.
- «Что входит в программу?» → состав с конкретной страницы Tilda, ссылка на него.
- «Есть ли конкретная услуга?» → поиск по опубликованным страницам, без выдуманных услуг.
- «Сколько стоит приём?» → актуальная цена, если она опубликована, иначе уточнить у клиники.
- Ответы на русском и казахском, язык определяется по сообщению или выбирается вручную.

Медицинские вопросы: справочная информация о размещённых услугах, без диагноза или индивидуального назначения лечения.

## Изменения на сайте

1. В Tilda обновили страницу и опубликовали её.
2. GitHub Actions по расписанию обнаруживает изменённый контент и повторно индексирует только изменённые страницы.
3. Индекс проходит проверку публичности, секретов и достоверности source URL.
4. Новая версия публикуется атомарно; при ошибке остаётся предыдущая.
5. Вопросы о ценах могут инициировать дополнительную проверку свежести источника.

Удалённые или закрытые страницы исключаются из индекса. Для обновления не нужно вручную создавать карточки знаний.

## Безопасность с первого дня

- Сканировать только разрешённые HTTPS-домены и **общедоступный видимый контент**.
- Не индексировать скрипты, скрытые блоки, Tilda settings, токены, формы и персональные данные.
- Защита от SSRF, prompt injection, XSS, утечек, злоупотреблений API и перерасхода бюджета.
- Cloudflare secrets для LLM API. Не хранить секреты в GitHub и собранном индексе.
- В ответах ссылки формируются **из серверных проверенных источников**, а не произвольно моделью.
- Не сохранять пользовательские диалоги или сведения о здоровье по умолчанию.
- На публичном репозитории размещать только код и документацию, без результатов индексации с непроверенными данными.

Полная модель угроз: [docs/SECURITY.md](docs/SECURITY.md).
